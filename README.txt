🇯🇵 BUNPOU JOURNEY
Your Japanese Learning Adventure

Bunpou Journey adalah aplikasi pembelajaran bahasa Jepang untuk pemula yang dirancang untuk membuat proses belajar lebih interaktif, menyenangkan, dan terstruktur.

✨ Features
- Bunpou Dojo** – Mempelajari pola tata bahasa Jepang.
- Vocabulary** – Mengenal dan menghafal kosakata.
- Mini Games** – Berlatih melalui permainan interaktif.
- Review Library** – Mengulang materi yang telah dipelajari.
- JLPT Roadmap** – Melihat tahapan pembelajaran JLPT.
- Progress Tracker** – Memantau perkembangan belajar.

🛠️ Built With
- HTML
- CSS
- JavaScript
- Firebase Authentication
- Cloud Firestore

🚧 Project Status
Currently in Development
Materi awal mencakup 20 pola tata bahasa JLPT N5. Pengembangan materi dan fitur lainnya akan dilakukan secara bertahap.
